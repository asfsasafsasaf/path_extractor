# ОСТОРОЖНО!!!!!! БЕСПОЛЕЗНО!!!!!!!!

Скрипт осуществляет поиск и сбор всех путей к конкретным файлам из Search results.txt на диске C:\ 

(По аналогии с функционалом утилиты spokown-pathsparser) 

После чего экспортирует полученные данные в текстовый файл (.txt) по умолчанию или в указанную директорию.

Папки, мусорные и несуществующие пути отбрасываются, дубликаты убираются.
